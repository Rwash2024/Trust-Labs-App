# مركز الحملات (Trust Labs) · Campaign Hub

أداة شخصية لمحمد: بتكتب فيها فكرة حملة وتطلع لك خطة الشهر ومحتوى جاهز للنسخ. مجانية بالكامل، وشغّالة على جهازك بس.

## التشغيل

```bash
cd campaign-dashboard
npm install
npm run dev      # يفتح على http://localhost:5195
npm test         # الاختبارات
```

## الاستخدام

1. اكتب **فكرة الحملة** واختار الشهر وعدد (بوست / ريلز / كاروسيل / استوري)، واضغط «جهّز الخطة».
2. **التقويم:** اسحب أي منشور ليوم تاني، واختار المنصات والمواعيد من «المنصات والمواعيد».
3. **المنشورات:** لكل منشور أزرار «نسخ» للعنوان (للإليستريتور)، الكابشن، الهاشتاجات، نص اللوح، وبرومبت الصورة.
4. **زر «انسخ الأمر»:** بيجهّز أمر كامل للصقه في ChatGPT أو Gemini أو Claude. النتيجة (JSON) تستورّدها بزر «استيراد ملف».
5. **المنافسين:** مقارنة + «الفراغ وإزاي نكسب». **بنك الأفكار:** الأفكار القديمة، وتحذير لو الفكرة الجديدة شبه قديمة.

## الحفظ

البيانات بتتحفظ في المتصفح. استخدم **تصدير الملف** كنسخة احتياطية، و**استيراد ملف** لمحتوى الشهر اللي بيكتبه Claude.

## ملاحظات

- برومبت الصورة بيطلع **الصورة + اللوح الزجاجي فقط**. اللوجو والكبسولة والعنوان من قالب الإليستريتور.
- بيانات المنافسين مبدئية (انستجرام بس، عينة صغيرة). فيسبوك والبرج وعز لاب والشمس وميد لاب لسه ناقصين.
- محرك الكتابة قابل للتبديل في `src/lib/engine.js` (ممكن نوصّل Gemini أو Claude API لاحقًا).
- التصميم: الشريط الجانبي الزجاجي مستوحى من فيديو «Glassy SideBar» اللي حطه محمد.

## الحفظ على السحابة (اختياري)

- بيحتاج متغيّرين في `.env.local` (أو في إعدادات Vercel): `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` (المفتاح العام بتاع مشروع Supabase، مش السرّي).
- من الشريط أعلى الصفحة: «سجّل دخول للحفظ على السحابة» بحساب **أدمن** بتاع تطبيق معامل ترست. الباسورد بيتبعت لـ Supabase بس ومبيتخزّنش.
- بعد الدخول بيتحفظ تلقائيًا بعد كل تعديل، وفي نسخة واحدة مشتركة (جدول `campaign_hub_state`، صف واحد). لو النسخة اتغيّرت من جهاز تاني بيسألك تستخدم أنهي واحدة.
- الأمان: الجدول عليه RLS للأدمن بس (نفس نمط `app_metadata.role = 'admin'` في باقي الجداول)، ومفيش حذف.
- من غير الإعدادات دي الأداة بتشتغل محليًا زي الأول.
